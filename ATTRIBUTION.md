# Authorship and provenance

Meridian is an original fictional world developed for druidqwerty with AI coding
assistance. Geometry, settlement layouts, narrative, buildings, furnishing rules,
landscaping and runtime policies were authored for this project. No geographical
database or real building footprint is used.

`tools/map_binary.py` and `tools/worldmap_binary.py` are reusable original native
B42 codecs retained in the local PZ Map Tools repository. Their historical MIT
notice remains in [tools/CODEC-LICENSE.txt](tools/CODEC-LICENSE.txt); historical
project names in that notice do not revive an old map. The format documentation
also credits KnoxMap by euclid80tr, https://github.com/spytheeuclidean-a11y/knoxmap.
No external compiler or upstream game map is bundled.

Project Zomboid sprite identifiers refer to assets supplied by the player's own
installed game. The Indie Stone owns the game and its artwork; these are not
included in the release. Real USA was available as an inspection reference only;
no Real USA building, code, world data or artwork was copied.

Viewpoint by Spiffo and ZombieBuddy are external, optional compatibility targets.
Their JARs, textures and code are not distributed. The developer-only oracle uses
separately installed local QA helpers; those dependencies are documented in QA.

The support banner is the owner's existing shared mod banner. Route illustration
is an original schematic of this world's generated geometry, not a game screenshot.
